# Видеопрокат API

Бэкенд TV Shows Explorer на Go: поиск сериалов через TVmaze с кешем, фильтр
по жанрам, пагинация и избранное. Фронтенд лежит в `../Homework_1`
(React + MobX, GitHub Pages).

Репозиторий: https://github.com/wildbober228/it-sinyak-homework_1_backend

## Архитектура

Перед любой разработкой (новая фича, таска, стор, перенос кода) сверяйся с
правилами из `ARCHITECTURE.md` и следуй им. Если задача противоречит правилам —
сначала скажи об этом, а не отступай от них молча.

@ARCHITECTURE.md

Поменял контракт API — обнови `../Homework_1/src/**/logic/api.ts` и таблицу в
`ARCHITECTURE.md` в том же изменении.

После изменений `make check` должен проходить без ошибок.

## Запуск

- `make run` — сервер на `:8080`.
- `PORT` — порт (Render задаёт сам).
- `ALLOWED_ORIGINS` — разрешённые origin-ы через запятую, по умолчанию
  `http://localhost:5173,http://localhost:4173`.

## Деплой

Render, Blueprint из `render.yaml`, бесплатный план. Сервис засыпает через
15 минут без трафика и просыпается до минуты, память при этом стирается.
Прогрев на фронте идёт через `GET /api/health`.
